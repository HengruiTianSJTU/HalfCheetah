# 4090 GPU 实现结果

从本地打开 [视频目录](index.html)，可以按实验类型选择视频，并找到对应权重。
这些是本组在 RTX 4090 上实际完成的正式复现实验，不是原作者 CPU 实验的权重。

## 下载

仓库使用 Git LFS 保存本目录的 MP4 和两批 4090 实验的 `checkpoint.pt`。
安装 Git LFS 后，在克隆的仓库目录运行：

```bash
git lfs install
git lfs pull
```

若文件内容以 `version https://git-lfs.github.com/spec/v1` 开头，说明当前只有
Git LFS 指针，需要下载真实对象。普通 GitHub ZIP 下载不应被当作已下载全部
二进制的保证。图表与 Tutorial 的 CSV 数据不依赖 LFS，可以直接查看或重新生成。

## 内容与计数

- `../reproduction_4090_20261030/`：26 次学习率/clip 正式实验的权重、配置和日志。
- `../entropy_sweep_20261030/`：20 份熵系数实验权重，其中 5 份为上一批的复用基线。
- 合计 **46 个权重路径、41 个不同的训练模型**；复用基线不能重复计为新增训练。
- `4090_gpu/experiment_story.mp4`：26 次学习率/clip 实验与模型选择的 2 分 52 秒叙事视频。
- `4090_gpu/final_policy_extended.mp4`：该批最终策略的完整 50 秒展示。
- `4090_gpu/clips/`：26 个模型的固定验证初始状态演示，加筛选与最终测试回看，共 29 个。
- `4090_gpu/entropy/`：四种熵系数 × 五个训练种子的 20 个完整单模型演示。
- `4090_gpu/comparisons/`：五个学习率/clip 参数组、四个熵系数组的种子对比，以及一个固定训练种子的熵系数对比。

每段单模型视频为 1000 帧、20 fps、50 秒，正常速度播放。文件名标明训练种子
与演示初始种子。主实验模型在新的 `reproduction_4090_20261030` 目录中发布，
没有把 GPU 权重放进原作者 CPU 实验的同名目录。

这里发布全部正式实验的最终权重与可观看成片；短流程速度测试、过期的未扩展地面
演示和剪辑过程中的临时片段不计入正式结果。

## 回报与硬件说明

“4090 GPU 实现结果”指模型训练使用 RTX 4090 的 CUDA。为延续原视频的评估方式，
视频采用 CPU 上的确定性均值动作，EGL 渲染地面扩展后的画面。CPU 与 CUDA 的
浮点差异可能改变接触轨迹，因此单个视频回报与 CUDA 训练日志的同种子回报不一定
完全相同。视频元数据与组统计分别保留，不能把单回合演示当作参数组均值。

新增熵视频均在原环境上用相同 CPU 推理方式复核，地面视觉修改前后的回报差异
为 0。地面半宽为 2000 米。所有演示使用固定初始状态，未按视频效果挑选种子。

26 次主实验选出的模型为学习率 0.0003、clip 0.3、训练 seed 44；独立 20 回合
测试回报 6922.1 ±66.2，平均速度 7.383 m/s。熵实验固定 clip 0.2，只报告验证
结果；新增视频没有触发重新选择最终模型，也没有新增独立测试成绩。

## 检查与重新渲染

`4090_gpu/manifest.json` 将视频与权重 SHA-256、配置、训练种子、演示种子对应。
从仓库根目录运行：

```bash
python scripts/check_4090_artifacts.py

# 选择自己的可用 EGL 设备；示例保存到新的本地文件，不覆盖已发布视频。
MUJOCO_GL=egl MUJOCO_EGL_DEVICE_ID=0 python scripts/render_4090_policy.py \
  results/entropy_sweep_20261030/hc_entropy0.001_seed42/checkpoint.pt \
  --seed 10000 --output .local/entropy_seed42_demo.mp4
```

该渲染脚本只接受可信的本地 PyTorch 权重。播放器不直接在网页中执行模型。
已有故事视频保持其 26 次主实验叙事，熵系数作为独立补充在同一目录浏览。
