02 / PPO：让每次策略更新更克制

Actor 输出动作分布，Critic 估计 V(s)。采集 rollout 后计算 GAE，归一化优势，打乱 minibatches，多轮优化 clipped objective 与 value loss。下一次 rollout 使用更新后的策略。

ρ = πθ(a|s) / πold(a|s)
Lclip = min(ρ A, clip(ρ, 1−ε, 1+ε) A)

拖动 clip 与优势，观察 surrogate 的变化

横轴是动作概率比，纵轴是最大化的目标。正优势限制过大的概率增幅；负优势限制过大的概率减幅。Clipping 不是 KL 的硬约束，也不保证回报单调上升。

展开 GAE 与时间截断解释

δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)，Aₜ = δₜ + γλAₜ₊₁。真正 terminated 的 next value 为零；TimeLimit truncated 使用最终观测的价值。两种结束都阻断优势递推，避免把 reset 后轨迹接到旧 episode 上。训练使用 reward 尺度标准化；评估使用原始环境回报并冻结 observation 统计。

实现入口：ppo.py / train.py。算法来源：PPO 原始论文。

03 / 超参数如何改变学习

比较固定预算内的全程学习与末次 evaluation，而非挑选单次 stochastic episode。每个评估点使用固定的 held-out 初始种子；阴影是训练 seed 均值的 ±1 sample SD，不是置信区间。

AUC 为 evaluation mean 对环境步数积分后除以步数区间。5 episode evaluation 的回合波动与跨训练 seed 方差是不同量。3 个训练 seeds 只能给有限证据，不能泛化为超参数的普遍排名。

04 / 保存失败，而不是只展示最好曲线

激进 learning rate 实验检验过大更新是否破坏学习；如结果较差，只能把该差异归因于本设计下的关联。结合 policy KL、clip fraction、value loss 与真实回报审阅，不能仅凭曲线推断唯一因果机制。

07 / 从连续控制到智能无线组网

HalfCheetah 是算法 benchmark，不是无线网络仿真。可迁移的是连续策略、价值估计、稳定更新和多 seed 验证方法。例如：以信道增益、干扰和队列作为状态，以发射功率或带宽份额作为动作，以吞吐、能耗与时延组合为 reward。

真实网络还需处理部分可观测、非平稳多用户交互、QoS 约束与上线风险。连续动作策略不能自动保证网络可行域，需要额外的约束设计与真实网络验证。本项目不宣称取得了无线性能提升。
